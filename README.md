# Istanbul Travel Guide Website

## Overview

The Istanbul Travel Guide Website is a responsive web application designed to help international students and travelers explore Istanbul's most popular destinations, attractions, and travel resources.

The platform provides essential travel information through an intuitive and user-friendly interface, making it easier for visitors to plan their journeys and discover the city's rich cultural and historical heritage.

---

## Features

* Responsive and mobile-friendly design
* Modern and intuitive user interface
* Information about major tourist attractions
* Travel guidance and practical tips
* Destination exploration pages
* Interactive image gallery
* Contact and information page
* Easy navigation across all sections
