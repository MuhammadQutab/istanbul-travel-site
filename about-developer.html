Developer page

Role and project scenario

This site was created as a web authoring assessment. The scenario presents myself as a junior developer at Tech Brains Ltd, producing a travel and tourism website focused on Istanbul. The website is built using HTML and CSS only, with consistent navigation and accessible structure.

  • Student identifier: STU207717
  • Development tools: Visual Studio Code
  • Technology stack: HTML5 + CSS3

Technical implementation

  • Semantic HTML structure (header, nav, main, footer)
  • Consistent navigation across all pages
  • Responsive layout using CSS grid and breakpoints
  • Optimised image usage (12 total) with meaningful alt text
  • Accessibility improvement: “Skip to content” link

Testing plan for evaluation

  • Cross-browser test (Chrome, Edge, Firefox)
  • Responsive test (desktop, tablet, mobile)
  • HTML validation for all pages + CSS validation
  • Document issues found and fixes applied

These points can be used directly in your Task 3 testing/evaluation write-up.
